# Как с помощью API узнать, что товар добавлен для продажи в Магазине на Kaspi.kz?

*updated: 12.06.2024*

*canonical: /shop/api/goods/q3221*

Для этого отправьте API-запрос. Можно использовать любой сервис, например, Postman, Insomnia, Paw, Swagger, SoapUI или настроить интеграцию с вашей системой учета.

|  |  |
| --- | --- |
| **Параметр** | **Значение** |
| i | Код загрузки товара    *Чтобы его получить:*   * *с помощью**API**в Магазине на**Kaspi**.**kz**добавьте товар для продажи;* * *скопируйте значение атрибута «**code**».* |

Посмотреть пример запроса

Скопировано

```
GET
https://kaspi.kz/shop/api/products/import?i=testproduct&HTTP/1.1=&Host=kaspi.kz
Accept: application/json
X-Auth-Token: token
```

В ответе вы получите информацию о статусе обработки.

|  |  |
| --- | --- |
| **Атрибут** | **Значение** |
| code | Код загрузки товара |
| status | Статус обработки |
| description | Описание от продавца |

Посмотреть пример ответа

Скопировано

```
 {
    "code": "testproduct ",
    "status": "FINISHED"
}
```
