# 1. Как с помощью API в Магазине на Kaspi.kz получить список моих заказов?

Для этого отправьте API-запрос. Можно использовать любой сервис, например, Postman, Insomnia, Paw, Swagger, SoapUI или настроить интеграцию с вашей системой учета.

## Параметры запроса

+----------------------------------+--------------------------------------------------------------+
| Параметр                         | Значение                                                     |
+==================================+==============================================================+
| page[number]                     | Номер страницы с результатом запроса                         |
|                                  |                                                              |
|                                  | На одной странице может быть максимум 100 заказов            |
|                                  |                                                              |
|                                  | Укажите номер нужной страницы, начиная с 0                   |
+----------------------------------+--------------------------------------------------------------+
| page[size]                       | Количество заказов, которое будет на одной странице в ответе |
|                                  |                                                              |
|                                  | Максимум — 100                                               |
+----------------------------------+--------------------------------------------------------------+
| filter[orders][state]            | Состояние заказа                                             |
|                                  |                                                              |
|                                  | NEW                  — новый                                 |
|                                  | SIGN_REQUIRED        — нужно подписать документы             |
|                                  | PICKUP               — самовывоз                             |
|                                  | DELIVERY             — ваша доставка                         |
|                                  | KASPI_DELIVERY       — Kaspi Доставка                        |
|                                  | ARCHIVE              — архивный                              |
+----------------------------------+--------------------------------------------------------------+
| filter[orders][creationDate]     | Дата создания заказа                                         |
|                                  |                                                              |
|                                  | Указывается в миллисекундах                                  |
|                                  |                                                              |
|                                  | [$ge] — начальное значение                                   |
|                                  | [$le] — конечное значение                                    |
+----------------------------------+--------------------------------------------------------------+
| filter[orders][status]           | Статус заказа                                                |
|                                  |                                                              |
|                                  | APPROVED_BY_BANK                  — продавец должен его      |
|                                  |                                     принять                  |
|                                  | ACCEPTED_BY_MERCHANT              — принят                   |
|                                  | COMPLETED                         — завершен                 |
|                                  | CANCELLED                         — отменен                  |
|                                  | CANCELLING                        — в процессе отмены        |
|                                  | KASPI_DELIVERY_RETURN_REQUESTED   — ожидает возврата         |
|                                  | RETURNED                          — возвращен                |
+----------------------------------+--------------------------------------------------------------+
| filter[orders][deliveryType]     | Способ доставки                                              |
|                                  |                                                              |
|                                  | Используйте, только если filter[orders][state] не равен      |
|                                  | PICKUP                                                       |
|                                  |                                                              |
|                                  | DELIVERY, KASPI_DELIVERY или PICKUP                          |
|                                  |                                                              |
|                                  | PICKUP   — самовывоз                                         |
|                                  | DELIVERY — доставка                                          |
+----------------------------------+--------------------------------------------------------------+
| filter[orders][signatureRequired]| Подписание документов                                        |
|                                  |                                                              |
|                                  | Используйте, если filter[orders][state] не равен             |
|                                  | SIGN_REQUIRED                                                |
|                                  |                                                              |
|                                  | true  — необходимо                                           |
|                                  | false — не требуется                                         |
+----------------------------------+--------------------------------------------------------------+
| include[orders]                  | Дополнительные данные о заказе                               |
|                                  |                                                              |
|                                  | user — Информация о покупателе, который оформил заказ        |
+----------------------------------+--------------------------------------------------------------+

## Посмотреть пример запроса

```
GET
https://kaspi.kz/shop/api/v2/orders?page[number]=0&page[size]=20&filter[orders][state]=NEW
&filter[orders][creationDate][$ge]=1478736000000&filter[orders][creationDate][$le]=1479945600000
&filter[orders][status]=APPROVED_BY_BANK&filter[orders][deliveryType]=PICKUP
&filter[orders][signatureRequired]=false&include[orders]=user
Content-Type:application/vnd.api+json
X-Auth-Token: <token>
```

В ответе вы получите информацию о каждом заказе.

| customer                         | ФИО и номер телефона покупателя                              |

| deliveryMode                     | Способ доставки                                              |

|                                  | DELIVERY_LOCAL — по городу — Kaspi Доставка или силами       |

| preOrder                         | Оформлен по предзаказу                                       |

+----------------------------------+--------------------------------------------------------------+
| state                            | Состояние заказа                                             |
|                                  |                                                              |
|                                  | NEW                  — новый                                 |
|                                  | SIGN_REQUIRED        — нужно подписать документы             |
|                                  | PICKUP               — самовывоз                             |
|                                  | DELIVERY             — ваша доставка                         |
|                                  | KASPI_DELIVERY       — Kaspi Доставка                        |
|                                  | ARCHIVE              — архивный                              |
+----------------------------------+--------------------------------------------------------------+
| creationDate                     | Дата создания заказа                                         |

|                                  | Указывается в миллисекундах                                  |
+----------------------------------+--------------------------------------------------------------+
| approvedByBankDate               | Дата одобрения заказа банком                                 |

|                                  | Указывается в миллисекундах                                  |

| plannedDeliveryDate              | Планируемая дата доставки                                    |
|                                  |                                                              |
|                                  | Указывается в миллисекундах                                  |
+----------------------------------+--------------------------------------------------------------+
| reservationDate                  | Дата доставки по предзаказу                                  |
|                                  |                                                              |
|                                  | Указывается в миллисекундах                                  |
+----------------------------------+--------------------------------------------------------------+
| status                           | Статус заказа                                                |
|                                  |                                                              |
|                                  | APPROVED_BY_BANK                  — продавец должен его      |
|                                  |                                     принять                  |
|                                  | ACCEPTED_BY_MERCHANT              — принят                   |
|                                  | COMPLETED                         — завершен                 |

|                                  | CANCELLING                        — в процессе отмены        |

|                                  | RETURNED                          — возвращен                |
+----------------------------------+--------------------------------------------------------------+
| deliveryCost                     | Стоимость доставки                                           |
+----------------------------------+--------------------------------------------------------------+

+----------------------------------+--------------------------------------------------------------+
