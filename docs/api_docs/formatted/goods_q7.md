# Я с помощью API добавил товары для продажи в Магазине на Kaspi.kz. Как узнать результат?

*updated: 12.06.2024*

*canonical: /shop/api/goods/q3222*

Для этого отправьте API-запрос. Можно использовать любой сервис, например, Postman, Insomnia, Paw, Swagger, SoapUI или настроить интеграцию с вашей системой учета.

|  |  |
| --- | --- |
| **Параметр** | **Значение** |
| i | Код загрузки товара |

Посмотреть пример запроса

Скопировано

```
GET
https://kaspi.kz/shop/api/products/import/result?i=testproduct&HTTP/1.1=&Host=kaspi.kz
Accept: application/json
X-Auth-Token: token
```

В ответе вы получите детальный результат проверки товара.

|  |  |
| --- | --- |
| **Атрибут** | **Значение** |
| errors | Количество товаров с ошибкой |
| warnings | Количество товаров с предупреждением |
| skipped | Количество товаров с пропуском |
| total | Количество загруженных товаров |
| state | Результат загрузки |

Посмотреть пример ответа

Скопировано

```
 {
    "errors": 0,
    "warnings": 0,
    "skipped": 0,
    "total": 1,
    "result": {
        " Testsku": {
            "state": "FINISHED"
        }
    }
}
```
