## Efficient Cleanup Strategy

Recommended next route:

1. Keep the Phase42 CodeCaptain pack as the current review surface.
2. Ask the owner for explicit local evidence cleanup approval before deleting copied DB artifacts.
3. Delete only non-production copied DB files under `exports/validation` that have preserved SHA files, validator matrices, closeouts, or Oracle pack summaries.
4. Do not delete production `db/app.db`, workbooks, source inputs, CSV/JSON/TXT evidence, closeouts, Oracle packs, or source downloads.
5. Record a deletion manifest with path, size, and reason before removal.
6. Re-run `df -h .`, `bash scripts/check_no_db_tracked.sh`, and protected-surface SHA checks after cleanup.

Target runway before another copied-DB wave:

- Minimum: `3 GiB` free.
- Preferred: `8-10 GiB` free, because C3 materializers can create multiple backups if not tightly configured.
